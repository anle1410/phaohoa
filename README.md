## 🌌 Giới thiệu

Dự án này là một trang web mô phỏng pháo hoa bằng HTML, CSS và JavaScript, sử dụng Canvas để tạo hiệu ứng pháo hoa động, nhiều màu sắc, chuyển động mượt mà và màn hình nền tối. Trang có thể chạy trực tiếp trên trình duyệt mà không cần cài đặt thêm phụ thuộc phức tạp.

Website bao gồm:
- hiệu ứng pháo hoa liên tục
- giao diện điều khiển trực quan
- tùy chọn chất lượng hình ảnh
- chế độ fullscreen
- âm thanh và cài đặt hiển thị
- trải nghiệm tối ưu trên desktop và mobile

---

## ✨ Tính năng chính

- Pháo hoa phát nổ theo nhịp tự động
- Nền tối, giao diện hiện đại, bắt mắt
- Hỗ trợ nhiều màu sắc pháo hoa: đỏ, xanh, tím, vàng, trắng
- Tùy chỉnh kích thước và kiểu đạn pháo hoa
- Chế độ chất lượng hình ảnh: thấp, bình thường, cao
- Tùy chọn ánh sáng bầu trời
- Chế độ phát pháo tự động / cuối màn hình
- Ẩn/hiện điều khiển nhanh chóng
- Open shutter hiệu ứng ánh sáng dài
- Hỗ trợ fullscreen
- Giao diện responsive với màn hình lớn và nhỏ

## 🧩 Cấu trúc dự án

```text
pháo bông/
├── fireworks.html   # Cấu trúc giao diện trang web
├── styles.css       # Thiết kế giao diện và bố cục
├── script.js        # Logic tạo pháo hoa và hiệu ứng canvas
├── README.md        # Tài liệu hướng dẫn dự án
└── assets/          # (nếu mở rộng sau này)
```

---

## 🕹️ Hướng dẫn chạy

### 1. Mở terminal hoặc PowerShell

```bash
cd "d:\pháo bông"
```

### 2. Khởi động máy chủ web

Nếu máy có Python: 

```bash
py -m http.server 8000
```

### 3. Mở trình duyệt

```text
http://localhost:8000/fireworks.html
```

> Nếu bạn đang mở trực tiếp file `.html` bằng trình duyệt, có thể hoạt động nhưng tốt nhất nên sử dụng `localhost` để tránh lỗi liên quan đến tài nguyên và quyền truy cập.

## 🎛️ Các điều khiển trong web

Trang web có các nút và tùy chọn như sau:

- Pause / Resume: tạm dừng hoặc tiếp tục màn hình pháo hoa
- Sound: bật/tắt âm thanh
- Settings: mở menu cấu hình
- Shell Type: chọn kiểu pháo hoa
- Shell Size: chọn kích thước đạn pháo hoa
- Quality: điều chỉnh độ sắc nét của hiệu ứng
- Sky Lighting: chọn mức ánh sáng bầu trời
- Scale: thay đổi tỷ lệ hiển thị
- Auto Fire: phát pháo hoa tự động
- Finale Mode: chế độ bắn pháo hoa dồn dập, rực rỡ hơn
- Hide Controls: ẩn thanh điều khiển
- Fullscreen: xem trong chế độ toàn màn hình
- Open Shutter: tạo hiệu ứng mở màn hình ánh sáng dài

## 📸 Mô tả trải nghiệm

Trang web tạo cảm giác như bạn đang xem một buổi bắn pháo hoa ngoài trời vào đêm giao thừa hoặc sự kiện đặc biệt. Kết hợp mượt mà với nền đen và các màu sắc tương phản, toàn bộ giao diện mang cảm giác sang trọng và sôi động.
